# 🍽️ Recipe Manager App

A modern, full-featured **Recipe Manager** built with **Laravel**, **Vue 3**, **Inertia.js**, and **Tailwind CSS**. Organize, create, and explore recipes with a sleek and responsive UI.


## ✨ Features

- 📝 **Create & edit recipes** with rich instructions and grouped ingredients
- 👨‍🍳 **User profiles** with avatars and social links
- 🔍 **Search recipes** by name or ingredients
- 📊 **Categorized ingredient groups** for better organization
- 🖼️ **Beautiful parallax design** with responsive layout
- 🧠 Built with **Laravel Inertia stack** and **Tailwind CSS**
